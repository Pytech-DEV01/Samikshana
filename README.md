# Samikshana
Agentic AI, for MPLADS
Sameekshana is an MPLADS project-monitoring platform that brings project dashboards, progress reports, and review tools together.
It helps officials and citizens track work, spot delays or unusual spending, and support more transparent oversight.
Its innovation is combining data-driven risk signals with role-based collaboration—helping people focus attention where human review may be most useful.
